# Personal Blog

This repository contains the **content** and **configuration** of my personal site (ernest.sh) : technical articles, notes, and small experiments.  
It’s built with **Hugo** and auto-deployed via **GitHub Actions** on each push to `main`.

- Read the blog: https://ernest.sh
- Articles in `content/posts/`
- Theme: PaperMod (submodule in `themes/`)

> Want to build a similar site? I explained the process here: https://ernest.sh/draft-review-publish
